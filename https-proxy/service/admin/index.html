HTTPS reverse proxy

Default admin token: DOGECOIN (or HTTPS_PROXY_ADMIN_TOKEN). Dogebox maps each pup expose to a host port — see Forwarding public ports and Dogebox docs. This pup’s manifest declares two exposes: plain HTTP and HTTPS on different container ports (defaults 80000 / 44443, away from common 10000 / 10001). Use the panel’s mapped port for each: http://dogebox:<mapped HTTP>/__proxy/ for what Dogebox reverse-proxies, and https://dogebox:<mapped TLS>/__proxy/ for a direct TLS connection (self-signed; trust or accept the warning). Keep PUBLIC_PORT / HTTPS_PROXY_TLS_PORT consistent with those exposes if you change ports. Configure hostnames, listener ports, and upstreams below — then run probes to verify TLS and backends.
