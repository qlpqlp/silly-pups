HTTPS reverse proxy

Default: HTTPS on PUBLIC_PORT with a self-signed cert — open https://dogebox:<PORT>/__proxy/, accept the browser warning (or install cert.pem). Default admin token is DOGECOIN unless you set HTTPS_PROXY_ADMIN_TOKEN. If you see SSL_ERROR_RX_RECORD_TOO_LONG in Firefox, you used https:// while HTTPS was off — use http:// instead, or turn HTTPS on below. The port in the URL must match your pup’s PUBLIC_PORT. Admin stays at /__proxy on every listener.

On = self-signed cert and TLS (default). Off = plain HTTP only on the same ports.
